Security and controls

Business records should stay with the right business.

LEXA uses authenticated workspaces, role-based access and scoped business records to reduce unauthorized access and improve operational accountability.

Security foundations

Business separation

Data access is scoped to authorized businesses and branches. Financial operations use database-level tenant policies alongside application controls.

Staff permissions

Business roles and approval controls restrict sensitive operations such as financial posting and payroll access.

Transaction history

Financial workflows are designed around source-document references, journal history and controlled revisions.

Encrypted web traffic

The public domain uses HTTPS and strict TLS connections. Sensitive operations require authenticated requests.

Private documents

Supporting uploads use signed links, checksum verification and a security review process before download access.

Continuity

Authoritative data belongs in approved database backups and recovery workflows rather than relying on local browser state.

Safety depends on ongoing verification.

Security controls, hosting configuration and permissions must be maintained and tested over time. This page describes intended safeguards, not a third-party security certification or guarantee against all threats.
