# LEXA brand guidelines

LEXA uses a restrained business-software palette with midnight navy, royal blue, cyan, emerald, gold, orange and signal red. Navy anchors the application shell; blue is the primary action colour; cyan is used for interaction; emerald signals successful states; gold and orange provide careful emphasis; red is reserved for destructive or critical states.

The supplied LEXA wordmark is the primary identity mark. Do not repeat multicolour gradients on every card or panel. Preserve strong contrast, semantic status colours, keyboard focus visibility, responsive navigation and reduced-motion preferences.

The implementation tokens live in `lexa-frontend/src/styles/lexa-brand.css` and the shared application styles. Source CSS is checked in as build input; the production build must not rewrite application source.
