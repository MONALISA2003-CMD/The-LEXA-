# LEXA Official Identity — implementation and validation report

**Reference artwork:** the user-approved LX symbol and LEXA letterforms provided 4 November 2026. No geometric redesign of the logo was introduced.

## Delivered

- Converted the existing approved transparent symbol and wordmark into a consistent complete master lockup for light and navy surfaces. Preserved the original interlocking LX shapes and the X in the wordmark.
- Replaced the sidebar's CSS mask plus plain-text `LEXA` with the actual approved image-based LX and wordmark. Added adaptive LX marks for all 15 existing module accent keys, with dark-surface variants. Module colours come from `moduleAccents.ts` and keep the same symbol geometry.
- Replaced the placeholder `L` loading symbol and small sale-receipt mark with the approved LX symbol. Business-specific receipt identity remains business-led.
- Updated sign-in, first administrator setup, signup, verification, invitations, onboarding, public website and email templates to the approved master lockup. Separate light wordmark asset is used on navy surfaces.
- Created 16/32/48px PNG favicons, multi-size ICO, 180px Apple Touch Icon, 192px PWA icon, 512px maskable PWA icon and a manifest. Favicons always remain the official static blue/teal LX, not module-coloured.
- Updated public page headers, public-share preview metadata and an official 1200x630 social card; public pages keep master colours.
- Removed obsolete CSS logo image backgrounds and extra competing wordmark/placeholder rules. Tightened responsive dimensions for phone, tablet and desktop.
- Updated `complete_modules.py` to accept the new versioned favicon set, preventing regeneration from undoing the identity update.
- Added `backend/test/lexa-brand-identity.test.mjs` with regression tests for artwork, colour assets, icons, and page integration.

## Source-of-truth assets

- `lexa-frontend/public/lexa-master-symbol.png` and `lexa-master-wordmark.png`: transparent approved source geometry.
- `lexa-frontend/public/lexa-master-lockup.png` / `lexa-master-lockup-light.png`: complete lockups.
- `lexa-frontend/public/lexa-identity/*`: adaptive LX variants derived programmatically from the same master.
- `lexa-frontend/src/components/LexaLogo.tsx`: central workspace component; `variant`, `compact`, `accent`, `onDark`.
- `lexa-frontend/scripts/build_lexa_identity_assets.py` is a **developer-only** rebuild helper requiring Pillow/numpy. Its generated image files are committed; CI does **not** run this helper or install its Python dependencies.

## Not certified by this report

- Full dependency-backed frontend `tsc -b`, Vitest, Vite build and live authenticated end-to-end browser screens were **not** executed locally; the CI import pipeline must run those against its npm dependencies.
- These changes do not include DNS changes, production deployment or modifications to tenant data.
- Browser/favicon caching may persist temporarily. New icon and master asset URLs avoid the old rainbow-logo cache; production verification should check exact public URLs and refresh using a private browser session.
- Printing and business-issued documents must not be rebranded as if LEXA were the seller. The application retains the business identity on its receipts.
