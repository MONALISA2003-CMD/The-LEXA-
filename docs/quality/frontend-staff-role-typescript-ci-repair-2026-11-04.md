## Observed failure

GitHub Actions run `41828044762`, job `126567739936`, failed during `tsc -b && vite build` after backend tests, OpenAPI validation and frontend Vitest tests passed.

The three TypeScript diagnostics were:

- `AddEmployeePanel.tsx:108` TS2322 — HTML input `value` inferred as `string | boolean | string[] | undefined`.
- `AddEmployeePanel.tsx:129` TS2322 — the same problem in additional employee fields.
- `TeamAccessPanel.tsx:51` TS6133 — unused `e` in a checkbox `onChange` callback.

## Root cause and correction

`StaffDraft` contains both ordinary string fields and optional `allBranches?: boolean` and `branchIds?: string[]` fields. The component's input-field metadata was typed as `keyof StaffDraft`, so `form[f.name]` could include a boolean. React input `value` does not accept a boolean. The field metadata and text-setting function now use a `StaffTextField` mapped key type, derived from the actual `StaffDraft` properties whose non-nullable values are strings. The branch selection continues to use dedicated checkbox state.

The invitation branch selector's callback no longer declares the unused event parameter. No TypeScript compiler settings or diagnostics were disabled.
